# v1.1 迭代计划

## P0 — UI 缺口补齐

| # | 功能 | 后端端点 | 前端 API | 状态 |
|---|------|---------|---------|:--:|
| 1 | 账户注销页 | `DELETE /user/account` | `deleteAccount()` | API 已封装，UI 待实现 |
| 2 | 跑腿员排行榜 | `GET /runner/leaderboard` | `getLeaderboard()` | API 已封装，UI 待实现 |
| 3 | 附近任务（LBS） | `GET /task/nearby` | `getNearbyTasks()` | API 已封装，UI 待实现 |
| 4 | 任务统计页 | `GET /task/statistics` | `getTaskStatistics()` | API 已封装，UI 待实现 |

**设计要点**：
- 排行榜：分段展示（金银铜前三 + 列表），支持按接单数/评分/完成率排序
- 附近任务：腾讯地图 SDK 接入，Haversine 距离计算，LBS 排序 + 地图标记
- 账户注销：双重确认弹窗 + 支付密码验证 + 7 天冷静期（可选）
- 任务统计：环形图（状态分布）+ 折线图（7/30 天趋势）
